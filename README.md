# Landing Page

Hello!

My name is **Aleksandar**. I struggle with creativity when I have to come up with a topic for a website, so I decided to make something a little unusual. :)

This is the landing page for **decOdin** — a fictional website that teaches you how to forget every piece of code in your head. I found the idea funny and interesting, although, of course, this website has absolutely no real reason to exist.

For the first time during this course, I asked AI (ChatGPT) for a little help. The only thing AI created for this project were the images, based on my descriptions and ideas. So, credit for the illustrations goes to ChatGPT — I think it did a great job.

This project was quite challenging for me, and I spent a lot of time trying to get everything to a level I was satisfied with. Of course, I made plenty of mistakes along the way, so please don't treat this code as an example of how everything should be done. Looking back, there are already things I could have done differently or much better, but that is part of the learning process.
